01

Cockpit — the PR screen is the PR

The detail pane stops being a document with three sibling views. It is one PR screen: a three-line briefing, a Context row that stays collapsed until you ask, then the diff itself. The old Diff / Conversation / Explain tabs, their place headers and their footer are gone. What used to be behind those tabs sits in a 300px bar that never moves: review state, conversation, explanation. The Start review action renders findings as comment threads on the lines they belong to, so there is no second document to visit and no clicking to gather context.

  • 0No places. No tabs, no per-place header, no place footer. One detail bar, one screen.
  • 300One right bar. Review, conversation and explanation. Fixed, never a destination.
  • 40Context is a row. Collapsed by default; one line of preview, expand in place.
  • 44One diff strip. Totals, head SHA and view toggles replace the second toolbar.

02

Review — findings land where they are true

Start review no longer opens a second document. Each finding renders as a comment thread under the line it anchors to: severity on the 2px rail, the patch action in place, the reply box where the comment is. The bar keeps a six-row index so the shape of the review is visible without scrolling the diff, and Context is shown expanded here only to prove it grows in place — the shipped default is the collapsed row in artboard 01. The fullscreen control is out of scope for this pass and is absent from both screens.

  • 88Thread gutter. The two line-number columns, so a comment sits exactly on its line.
  • 6One index. The bar lists every finding; the diff holds the text.
  • 2Severity on the rail. Blocking and warning are carried by one 2px border, not by a card.
  • 1One primary. Re-run review in the bar foot; the diff only offers local actions.

Handshake: tolerate a bound port and print the real one

maya chen maya/sidecar-port → main 4 commits Checks passing Changes requested

The sidecar binds a random port, writes the handshake to stdout, and lets Tauri read it. When the port is already taken, the bind fails and stdout stays empty, so the window waits forever.

This patch retries the bind up to five times and prints the port it actually got. read_handshake now also fails fast when the child exits before printing.

03

The rules this mock enforces

The PR screen is one grid: briefing, Context row and diff on the left; a fixed 300px bar on the right. There are no place headers, no tab footers, and no second toolbar. Information that used to live behind tabs is either in the bar or on the line it describes. The numbers below all appear in the two artboards above.
