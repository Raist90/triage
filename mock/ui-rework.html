The sidecar binds a random port, writes the handshake to stdout, and lets Tauri read it. When the port is already taken, the bind fails and stdout stays empty, so the window waits forever.

This patch retries the bind up to five times and prints the port it actually got. read_handshake now also fails fast when the child exits before printing.

The retry approach is right, but the printed port can be seen before the listener is ready, and the loop does not notice a dead parent. Both are narrow races; the rest reads clean.

Findings 6 total
src-tauri/src/sidecar.rs:142 Blocking

Port is printed after the server starts

The handshake line is written once spawn returns, but the listener is bound inside the thread. A client can read a port that nothing is listening on yet. Print after TcpListener::bind succeeds, before the loop.

backend/cmd/triage-server/main.go:31 Blocking

Retry loop can outlive the parent

The five retries happen with no parent check, so a killed window leaves the sidecar retrying for the full backoff. Watch stdin or the process group and exit on EOF.

src/lib/api.ts:88 Warning

Handshake timeout is unbounded

The reader now fails fast when the child exits, but a child that hangs before printing still blocks the window. A short timeout keeps the first render responsive.

src-tauri/src/sidecar.rs:158 Nitpick

Backoff constant belongs at the top

The 250ms step is repeated in the retry branch. A named constant keeps the five attempts and the backoff in one place.

backend/internal/api/server.go:41 Nitpick

Comment repeats the function name

“Checks the bearer token” says nothing the signature does not. Say what happens on failure instead.

backend/internal/api/server.go:64 Praise

One place owns the bearer check

The middleware change is small and keeps token handling out of every handler. Good.

The rules this mock enforces

One grid, one band, one row recipe, one document measure. Every number below appears in the three artboards above; nothing else does. The current code ships roughly twice as many values — 10, 11, 26, 28px offsets, four footer heights, three row heights, a 23px title and a 36px toolbar — which is why the surfaces read as separate designs.
